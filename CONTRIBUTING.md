# Contributing

For bugs, include your Windows version, controller model and the steps that reproduce the problem. A short recording helps with navigation or animation issues. Remove personal details from logs before attaching them.

Keep PRs focused. Include the checks you ran, and a screenshot or recording for visible changes. Open an issue before a large feature or a new dependency.

Build and test commands are in [DEVELOPMENT.md](DEVELOPMENT.md). The browser mock is useful for UI work; controller and Windows integration changes also need a check in the native app.
